# 日記カレンダー

Google カレンダーと連携した、日記・写真・手書きメモ付きのオリジナルカレンダー(PWA)。
iPad / スマホ / PC のブラウザで動き、ホーム画面に追加してアプリのように使えます。

## 機能

- 月曜始まりの月表示。日本の祝日、二十四節気、雑節(彼岸・土用・入梅・八十八夜など)、年中行事(お盆・七夕・十五夜など)、六曜、旧暦を表示
- Google カレンダーの予定を表示・作成・編集・削除(複数カレンダー対応、表示切替可)
- 日付ごとの日記(テキスト)、写真の貼り付け(ファイル選択 / ドラッグ&ドロップ / Ctrl+V)、手書きメモ(Apple Pencil・液タブの筆圧対応)
- 月表示の上に直接手書き(紙のカレンダー感覚)。ヘッダーの「✎ 手書き」を押している間だけ描け、日付のタップで詳細が開くことはない
- 月表示の手書きはレイヤー分け可能(全月共通、最大 8)。レイヤーごとに表示/非表示、既定色、名前を設定。消しゴム・元に戻す・全消去は選択中レイヤーのみに効く
- 月表示を下にスクロールすると月ごとの「フリースペース」があり、同じ手書きモード・レイヤーで自由に書ける。用紙は下に伸ばせる(下端近くまで書くと自動)
- フリースペースの「余白ノートへ送る」で、その月の手書きを自作アプリ「余白ノート」の新しいページとして送れる(余白ノートと同じ Firebase に直接書き込む。初回のみ余白ノートのメールアドレスとパスワードでログイン)
- 日付の手書き欄にも「余白ノートへ送る」があり、その日の手書きと日記の文章(ページ上部の文字ブロック)を 1 ページとして送れる
- 日記データは自分の Google ドライブ(`マイドライブ/日記カレンダー`)に保存。サーバー不要
- 操作は Google カレンダー準拠: `t` 今日、`j`/`k` 翌月/前月、`c` 予定作成、ダブルクリックで予定作成
- 月の移動は横スワイプ(指・ペン)と、ヘッダー下の月ボタンの帯(前年〜翌年)でも可能

## セットアップ

### 1. Google Cloud の設定(初回のみ)

1. <https://console.cloud.google.com/> でプロジェクトを作成
2. 「API とサービス」→「ライブラリ」で **Google Calendar API** と **Google Drive API** を有効化
3. 「OAuth 同意画面」を作成(ユーザータイプ: 外部、アプリ名は任意)。
   テストユーザーに自分の Gmail アドレスを追加
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類「ウェブ アプリケーション」
   - 承認済みの JavaScript 生成元に、開発用 `http://localhost:5173` と、公開先の URL(例 `https://xxxx.vercel.app`)を追加
   - リダイレクト URI は不要
5. 発行されたクライアント ID を `.env` に書く

```
cp .env.example .env
# .env の VITE_GOOGLE_CLIENT_ID を書き換える
```

> 個人利用なので Google の審査は不要です。同意画面を「テスト」のままにしておくと、
> サインイン時に「このアプリは Google で確認されていません」と出ることがあります。
> その場合は「詳細」→「(アプリ名)に移動」で進めます。

### 2. 起動

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:5173> を開き、「Google でサインイン」を押します。

### 3. 公開(iPad・スマホから使う)

GitHub Pages に公開します。`main` ブランチに push すると GitHub Actions が自動でビルドして公開します
(`.github/workflows/deploy.yml`)。

1. GitHub でリポジトリ `nikki-calendar` を作成し、このフォルダを push する
2. リポジトリの Settings → Pages → Source を「GitHub Actions」にする
3. 公開 URL は `https://<ユーザー名>.github.io/nikki-calendar/`
4. Google Cloud の「承認済みの JavaScript 生成元」に `https://<ユーザー名>.github.io` を追加する

本番ビルドのクライアント ID は `.env.production` に書いてあります(公開値なのでリポジトリに含めて問題ありません)。
リポジトリ名を変える場合は `vite.config.ts` の `base` も合わせて変更してください。

iPad / iPhone では Safari で公開 URL を開き、共有 →「ホーム画面に追加」でアプリとして使えます。

## テスト

```bash
npm test
```

祝日・旧暦・六曜・節気・雑節の計算を検証します。

## データの保存先

- 予定: Google カレンダー本体(このアプリは Google カレンダーのクライアントとして動きます)
- 日記・手書き: `マイドライブ/日記カレンダー/entries/YYYY-MM-DD.json`
- 月表示の手書き: `マイドライブ/日記カレンダー/months/YYYY-MM.json`
- 手書きレイヤーの定義: `マイドライブ/日記カレンダー/settings.json`(表示/非表示と選択中レイヤーは端末ごとに記憶)
- 写真: `マイドライブ/日記カレンダー/images/`
- ブラウザ内にもキャッシュを持ち、オフライン中に書いた分はサインイン後に同期されます

## 構成

```
src/
  lib/astro.ts       太陽・月の黄経計算(旧暦・節気の基礎)
  lib/kyureki.ts     旧暦・六曜
  lib/holidays.ts    祝日
  lib/seasonal.ts    二十四節気・雑節・年中行事
  lib/google/        Google 認証・カレンダー・ドライブ API
  lib/diary.ts       日記の読み書き(ドライブ + ローカルキャッシュ)
  lib/monthInk.ts    月表示の手書きの読み書き
  lib/ink.ts         手書き共通(ペン設定・ストローク描画)
  components/        月表示・日別パネル・予定編集・手書きキャンバス
```
